## File naming conventions
- All new files in `src/components/`, `src/lib/`, `src/config/`, and `src/data/` must use **kebab-case** (e.g. `admin-header.tsx`, `photo-dialog.tsx`).
- Next.js reserved filenames (`page.tsx`, `layout.tsx`, `route.ts`, `loading.tsx`, `error.tsx`, `not-found.tsx`) keep their framework-required names.

## Build status
This project is an in-progress photo portfolio build. **Before continuing work, read `PROGRESS.md`** — it tracks phase status, the next step, intentional deviations from the original build doc (Prisma 7, Next 16 proxy, shadcn base-nova), and what inputs are still needed (notably the Lovable export for the public pages).
